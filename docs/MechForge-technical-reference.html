Packaging note. 8. Conventions, assumptions and limits

  • No copyrighted tables are embedded. Calculators implement and cite the engineering relations; code data (allowable stresses, flooding factors, design concentrations, listed equipment data) is entered by the engineer or imported into the reference library.
  • No compliance claim. A mathematically correct result is not a code-compliant design: the hazard classification, the edition in force, the manufacturer's listed data and the installation requirements remain the engineer's responsibility.
  • Base units. All arithmetic happens in SI base units; the UI converts in and out, and range checks are expressed in base units too.
  • Optional inputs change the shape of the answer (a missing S falls back to the ideal-gas estimate, a missing cylinder charge suppresses the cylinder block) and the calculator always shows which assumption it used, in the steps and in the warnings.
  • Offline. The Android app declares no INTERNET permission; everything is local. The only declared permission is POST_NOTIFICATIONS for the "report exported" notification.
